# Rose POS

Касса для официантов ресторана Rose (Минск, ул. Козлова 3). Меню с ценами, заказ, чек и настройки печати. Работает в браузере iPhone и Android, без сервера: заказы и чеки остаются на телефоне.

## Запуск

```bash
cd ~/Desktop/rose-pos
npm install
npm run dev
```

Откройте адрес, который покажет Vite. С телефона в той же сети Wi‑Fi откройте `http://<ip-компьютера>:5173`.

## На экран «Домой»

- iPhone: Safari → Поделиться → На экран «Домой».
- Android: Chrome → меню → Установить приложение.

После первой загрузки касса открывается и без сети.

## Как пробивать заказ

1. Нажмите карточку блюда. Повторное нажатие увеличивает количество.
2. У пива с двумя объёмами и у кофе сначала выбирается размер или альтернативное молоко.
3. Нижняя панель открывает заказ. Зелёная галочка справа ведёт к оплате.
4. Наличные, карта или перевод. На чеке будут название, адрес, сотрудник, дата и подпись про вознаграждение.
5. «Печать» отправляет чек на Bluetooth-принтер, если он подключён. Иначе открывается системная печать (AirPrint на iPhone). «Поделиться» отдаёт картинку или текст чека.

В настройках принтера те же поля, что у TinyPOS: ширина 80 мм, калибровка, кодировка, копии, шрифт, интервал, колонтитул и денежный ящик. Для русского текста на термопринтере выберите способ печати «Изображение» и кодировку CP1251, если остаётесь в режиме TXT.

Кнопка «Тест печати» печатает пробный чек и не пишет его в смену.
